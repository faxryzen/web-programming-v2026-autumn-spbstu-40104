# Лабораторная работа 3

## Задание

Вариант 25

Реализуйте функцию findEquilibriumIndex(arr), которая находит индекс, где сумма
левой и правой части массива равна.

## Реализация

Функция findEquilibriumIndex(arr) ищет индекс, где сумма левой и правой части
массива равна

- Генерирует исключение `TypeError`, если `arr` не `Array`
- Возвращает `-1`, если длина массива меньше трех. Также вернет -1, если в
  массиве будут не числа
- Находит полную сумму массива и проходится по нему, запоминая сумму слева и
  вычисляя справа. При совпадении - возвращает индекс

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
